Matrix Toolkit Build 071
Date: 2026-08-24

Fix from Build 070:
- The standard network settings are now APPLIED automatically during every install/update.
- Existing routers are corrected from old 2.4 GHz names such as JNLMatrix_2G to egym.
- 2.4 GHz radio is always enabled and SSID is always: egym
- 5 GHz radio is always enabled and country-specific:
  JNL = JNLMatrix_5G
  JBE = JBEMatrix_5G
  JDE = JDEMatrix_5G
- Mobile SIM1 remains primary Internet (metric 1).
- Ethernet WAN remains enabled as second/fallback Internet path (metric 10).
- Mobile SIM2 remains metric 2 when configured.
- Old Wi-Fi STA/client profiles remain disabled.
- All other Build 070 / Build 069 functionality is retained.
