Matrix Toolkit Build 070
Date: 2026-08-24

Changes from Build 069:
- Standard 2.4 GHz AP is always enabled as: egym
- Standard 5 GHz AP is always enabled as: <router hostname>_5G
  Examples: JNLMatrix_5G, JBEMatrix_5G, JDEMatrix_5G
- Mobile SIM1 Internet is primary (metric 1)
- Mobile SIM2 is secondary mobile path when configured (metric 2)
- Ethernet WAN remains enabled as fallback (metric 10)
- WAN IPv6 metric set to 11
- Old Wi-Fi STA/client interfaces are disabled by the standardizer
- Matrix Default profile changed to the same 2.4 egym + 5 GHz Matrix standard
- Emergency Wi-Fi restore now restores 2.4 egym + 5 GHz <hostname>_5G
- Existing Build 069 functionality retained
